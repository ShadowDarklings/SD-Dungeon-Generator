SD Dungeon Generator

SD Dungeon Generator creates and reveals Shadowdark-inspired procedural dungeons for solo players and DM-less tabletop sessions. It matters because it gives players a fast, browser-based way to explore rooms, doors, monsters, traps, and treasure without needing a prepared dungeon master.

1. Project name and pitch

SD Dungeon Generator is a web app for generating square-grid fantasy dungeons, placing the player in an entrance room, and revealing threats and rewards through fog-of-war play. The app serves Shadowdark RPG players who want a solo dungeon-delving tool or a quick generator for DM-less play.

3. Project type

Custom variant: procedural game/tool web app. The project combines an interactive browser game interface with generated map data, user authentication, saved dungeon runs, and AWS-hosted static content.

5. Web-based data source

API/platform: AWS S3 static website hosting and CloudFront, with future API Gateway and Lambda endpoints for saved dungeon runs.

Docs: Amazon S3 static website hosting and Amazon API Gateway .

Specific endpoint: http://shadowdarklings-dungeon-generator.s3-website-us-west-2.amazonaws.com/index.html for the team static site once the shared bucket is confirmed.

Free-tier notes: AWS free tier commonly includes limited S3 storage/requests and API Gateway/Lambda monthly request allowances for new accounts; the team will verify current limits in the AWS console before relying on them for production traffic.
