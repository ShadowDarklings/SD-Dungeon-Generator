# Treasure System Report

Generated after the coin pouch / Party Assets / XP changes and revised treasure table pass.

## Economy Target

Dungeon treasure targets roughly `4,000 gp x dungeon level`:

| Dungeon level | Total treasure target |
| --- | ---: |
| 1 | 4,000 gp |
| 2 | 8,000 gp |
| 3 | 12,000 gp |
| 4 | 16,000 gp |
| 5 | 20,000 gp |
| 6 | 24,000 gp |
| 7 | 28,000 gp |
| 8 | 32,000 gp |
| 9 | 36,000 gp |
| 10 | 40,000 gp |

Boss-room treasure is balanced as a share of the dungeon total:

- About 50% boss-room value / 50% scattered value is the common center.
- About 2% of levels push nearly all value into boss-room treasure.
- About 2% of levels put very little value into boss-room treasure.
- Values between those extremes progress around the 50/50 center.

## Coin Rules

- 1 gp = 10 sp = 100 cp.
- GP, SP, and CP are physical coins.
- 0-100 carried coins are free.
- 101-200 carried coins use 1 gear slot.
- 201-300 carried coins use 2 gear slots.
- This continues by 100-coin bands.
- Dungeon Features show coin pouches as `coin pouch ([n] cp)` where `[n]` is total value in copper pieces.
- Coin pouches split only into same-denomination floor piles.
- Coin pouch denomination is now weighted by dungeon level.

| Dungeon level | CP pouch weight | SP pouch weight | GP pouch weight |
| --- | ---: | ---: | ---: |
| 1 | 25 | 25 | 50 |
| 2 | 20 | 20 | 60 |
| 3 | 10 | 25 | 65 |
| 4 | 10 | 15 | 75 |
| 5 | 5 | 15 | 80 |
| 6 | 5 | 10 | 85 |
| 7 | 5 | 7.5 | 92 |
| 8 | 5 | 5 | 90 |
| 9 | 2.5 | 5 | 92.5 |
| 10 | 2.5 | 2.5 | 95 |

Note: dungeon level 7 totals 104.5 as provided, so the generator treats these numbers as relative weights and normalizes them.

## XP Rules Now In Code

- Picking up treasure does not award XP.
- Selling treasure in the start room increases Party Assets and checks XP.
- Every 100 gp of sold value per living character awards 1 XP to each living character.
- Fractional XP is tracked secretly per character and can roll into a later whole XP award.
- Loading a saved character can add that character's stored Party Assets share to the party, but does not award XP.

## Advice For The Next Revision

The new treasure value targets are high enough that treasure should create carrying choices instead of pure pickup bookkeeping.

- Reserve coins for 20-35% of total value.
- Put 45-60% of value into compact treasure: gems, jewels, rare instruments, ceremonial gear.
- Put 10-25% into awkward treasure: armor, bulky art, heavy trade goods, coin hoards.
- Give high-value awkward treasure a strong value-per-slot tradeoff so players choose what to carry.
- Consider a "claim treasure" rule in the start room: once a safe route is established, low-risk repeated hauling can be abstracted into one sale action.

Bulky treasures such as carriages, statues, furniture, altars, or trade goods are not yet implemented in this pass.
