# MCC Random Generator

A static browser utility for Mutant Crawl Classics tabletop prep.

It generates:

- NPCs with genotype, stats, equipment, and settlement-leader advancement
- Settlements with factions, barter goods, traps, and leaders
- Random encounters
- Ten-ring hex maps with settlements, encounters, radiation, coastlines, and player movement

## Use

Open `index.html` in a browser. No build step or server is required.

## Notes

This repo is intended as a personal tabletop utility. The original MCC PDF and working source documents are not included in this public-ready folder.
